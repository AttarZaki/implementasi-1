
# Prediksi Keberhasilan Pemasaran Bank

## Deskripsi
Proyek Machine Learning untuk memprediksi apakah nasabah akan berlangganan deposito berjangka menggunakan algoritma Random Forest.

## Teknologi
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Algoritma
Random Forest Classifier

## Evaluasi
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Dataset
UCI Machine Learning Repository - Bank Marketing

https://archive.ics.uci.edu/dataset/222/bank+marketing
